# Actual interface captures

This folder contains sanitized screenshots captured from the local Wrist Review
interface. They are **not** mockups and contain no MURA radiograph, patient
identifier, local data path, or model output from a real case.

| File | What it shows | Provenance |
|---|---|---|
| `01_add_study_actual_ui.png` | The actual Add Study screen before a file is selected | Local browser capture of the committed `apps/wrist_review` interface |

The browser frame and operating-system taskbar visible in this first capture
are not product UI. Future captures should be taken in a clean browser window
and should never contain a radiograph, patient identifier, identifying folder
name, or real study-level output.

The separately stored
[`../concepts/wrist_review_concept_storyboard.png`](../concepts/wrist_review_concept_storyboard.png)
is a **conceptual mobile storyboard**, not an actual interface capture.
